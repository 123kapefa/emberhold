# Процесс работы

- Задачи — Issues в `123kapefa/emberhold`, доска — Project «Emberhold» (Status, Priority P0–P2, Size S/M/L), этапы — milestones.
- Порядок по задаче: разобраться и найти причину → рассказать варианты → дождаться выбора → сделать ровно договорённое → тесты → отчёт.
- Ветка от свежего `main` → тесты зелёные (`Tools/unity-tests.sh`) → PR с `Closes #N` → карточка в «In review».
- Перед мержем — ревью, найденное исправить, тесты снова зелёные, потом мерж.
- Решения по игре — в `Docs/global/`, по технике — в `Docs/tech/`, в том же PR.
