## Ключевые решения
- Мир из блоков с уровнем заполнения и скосами; сутки 12 минут (6/1/4/1); свет — это территория: копать и строить можно только в свету (#98).
- Ресурсы: камень (из блоков), дерево (рубка, поленья). Земля при копке пропадает; даёт ли она материал для насыпи — #173.
- Проигрыш: главный костёр погас — отсчёт 10 с, потом конец забега (#53).
- Поселенцы (решено 2026-11-13, заменяет «игрок ставит роль»): постоянных ролей нет, все рабочие свободные; класс (копатель, лесоруб, строитель, истопник) даёт взятое задание и держится, пока задание есть; кто добыл — тот несёт на поддон; без дела — у огня (#161).
- Приказы: уровень обычный / высокий / срочный, срочный снимает с несрочной работы (#163).
- Зоны-задания: рубка — круг (#167); копка — прямоугольник-коробка Низ ≤ Уровень ≤ Верх, черновик до «Начать», ручки на границах (#136); выравнивание — #169. Приоритет на самой зоне не показывается: задания будут в интерфейсе (#162).
