# Зоны работ

Зона — задание из многих приказов: на неё идёт заданное число свободных рабочих, они держат класс, пока зона есть. Общее для всех зон:
- ставится **черновиком**: видна и настраивается, но рабочих не зовёт, пока не нажать «Начать» (Enter);
- панель зоны: размеры, приоритет, число людей, «Начать», «Снять зону»; клик внутри зоны выбирает её;
- **ручки** на выбранной зоне: стороны, углы, перенос целиком, высоты — по земле под курсором, не зависят от поворота камеры;
- приоритет на самой зоне не показывается.

## Зона рубки (#167, клавиша 8)
Круг с радиусом: рубят все деревья и корчуют все пни в нём, в том числе появившиеся позже. Рубка одного дерева инструментом 5 остаётся.

## Зона копки (#136, клавиша 9)
- Прямоугольник протяжкой ЛКМ; коробка из трёх высот **Низ ≤ Уровень ≤ Верх**.
- **Жёлтое** — (Уровень, Верх]: выкапывают слоями сверху; выше Верха не трогают. Скала и порода не копаются, тёмные блоки ждут света.
- **Голубое** — (Низ, Уровень]: место, которое наращивают до уровня; ниже Низа не трогают.
- По умолчанию: Уровень — на блок ниже клика, Верх — самый высокий блок прямоугольника, Низ — самая низкая земля.
- Вид: полупрозрачные объёмы, линия только по внешнему краю.

## Выравнивание (#169, в работе)
Режимы зоны: «Выкопать», «Нарастить», «Выровнять» (по умолчанию). Порядок — сначала снять всё жёлтое, потом наращивать снизу вверх. Насыпают землёй по текущим ценам (#173). Один общий счётчик людей: класс берётся из вида текущего приказа.
