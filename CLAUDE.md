# Emberhold — правила для агентов

- Документация в репозитории: игра, план и решения — `Docs/global/`, всё техническое — `Docs/tech/`. Решение по механике или процессу записывай туда в том же PR.
- Структура проекта и правила кода — `README.md`.
- Тесты Unity — только `Tools/unity-tests.sh` (см. `Docs/tech/testing.md`), Unity на Маке один на всех.
- Порядок работы и ревью перед мержем — `Docs/tech/workflow.md`.
